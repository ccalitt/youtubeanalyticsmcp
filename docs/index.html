Local Analytics

Local Analytics is a personal, read-only tool that lets the channel owner ask Claude about their own YouTube channel's analytics (views, watch time, retention, traffic sources) and public YouTube data. It runs entirely on the owner's own computer as a Model Context Protocol (MCP) server.

It is not a public service: it is used only by its developer for their own channel.
